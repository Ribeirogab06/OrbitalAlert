Como o monitoramento funciona

Esta é uma das páginas dedicadas à solução. Aqui mostramos, de forma simples, como o OrbitAlert transforma dados de satélite em alertas.

Etapas da solução

1. Coleta dos dados

O sistema busca dados abertos de satélites da NASA, ESA e INPE sobre temperatura, fumaça, umidade e cobertura vegetal.

2. Análise das informações

Os dados são comparados com valores de referência para identificar situações fora do normal.

3. Geração de alertas

Quando um risco é identificado, o sistema gera um alerta classificado como crítico, moderado ou baixo.

4. Aviso aos responsáveis

O alerta fica disponível na página de Alertas para municípios, produtores rurais e órgãos públicos.
